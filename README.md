# Hotel Cápsula para Mascotas - Salta Capital

Proyecto integral que combina el **Estudio y Formulación de Negocio Turístico** con la **Ingeniería y Desarrollo de la Plataforma Web de Reservas y Gestión**.

---

## 📁 Estructura del Repositorio

El proyecto se encuentra estructurado en dos grandes áreas dentro del directorio `docs/`:

```text
hotel-mascotas-app/
├── docs/
│   ├── negocio-academico/               # Proyecto de Negocio y Trabajo Integrador
│   │   ├── entregables/                 # PDFs, Word final, Proyección Económica en Excel
│   │   ├── inputs/                      # Diagnóstico FODA, Canvas, Localización (Tres Cerritos) y Mapas
│   │   ├── anexos/                      # Material complementario y anexos
│   │   └── TRABAJO_FINAL_HOTEL_CAPSULA_MASCOTAS.md
│   │
│   └── software/                        # Ingeniería de Software / Plataforma Web
│       ├── context/                     # Resúmenes consolidados de requerimientos y bitácora
│       ├── specs/                       # Requisitos funcionales (RF) y no funcionales (RNF) - SRS
│       ├── architecture/                # Diagramas C4, ERD, flujos de secuencia y decisiones ADR
│       ├── backlog/                     # Historias de usuario, sprints y roadmap
│       └── templates/                   # Plantillas de documentación técnica
│
└── [Próximamente: Código fuente de la aplicación en src/]
```
